# Expense Tracker (Python CLI)

A simple command-line Expense Tracker built with Python.
This program allows users to record expenses, categorize them, view all expenses, and calculate total spending.
This project stores data persistently using a JSON file, allowing users to retain their expense history between program runs.

## Features

- Add expenses with amount and category
- View all expenses
- Calculate total spending
- Delete expenses
- Data persistence using JSON
- Edit existing expenses

## How It Works

The program runs in a loop and displays a menu where users can choose different actions:

1. Add Expense
2. View Expenses
3. Show Total Spending
4. Exit
5. Delete Expense

Expenses are stored in a list using Python dictionaries.

## Technologies Used

* Python
* Lists and Dictionaries
* Loops and Conditional Statements
* Basic Error Handling
